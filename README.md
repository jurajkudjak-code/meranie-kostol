# Meranie teploty a vlhkosti

Verejná stránka meracej stanice (ESP32 + DHT22): **https://jurajkudjak-code.github.io/meranie-kostol/**

Súbor `index.html` sem automaticky nahráva samotná meracia stanica každých 15 minút
(GitHub API, token s právom zápisu iba do tohto repozitára). Ručne ho neupravujte –
pri ďalšom nahratí sa prepíše.

Dočasné riešenie, kým v sieti nebude Tailscale.
